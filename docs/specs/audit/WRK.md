# WRK audit - worker allocation engine (read-only, R3)

Scope read: `src/server/mis/worker-allocation.ts` (+test), `MisWorkerAllocation`/`MisMachineAllocation` in `prisma/schema.prisma`, `/mis/crew` page + actions, `worker-board-screen.tsx`, supervisor home crew card, `job-phases.ts` signOffPhase, `machines-board.ts`, production detail operator select, `print/job-card`, `attendance.ts`, `kiosk-device.ts` pull. Deferred items (#47 hard worker lock, #40/41/45 machine-board sync, #49 default shift) are not re-reported; where a finding touches them it says so.

## 2. End-to-end design gap list (what a complete allocation engine needs)

Current flow as built: Supervisor opens Machine Board, books a machine for an order/phase (`allocateMachine`, overlap refused). On `/mis/crew` (phone-only nav tab) the supervisor sees machines running NOW, taps "Assign crew", ticks free workers for the CURRENT shift, `assignWorkers` creates one `MisWorkerAllocation` per person (overlap = warn + confirm). Availability is derived each time. Audit rows `ASSIGN_WORKER`/`RELEASE_WORKER` are written. Home "My crew today" is attendance-only. The engine has 0 live rows because the loop is not closed anywhere else (below).

| # | Area | Gap | Today | Minimal addition | Schema? |
|---|---|---|---|---|---|

## 3. Minimal build order

No schema (can ship now, fixes the engine's correctness): WRK-01/02 cascade + derived-ended reads, WRK-03 array model or G3 move, WRK-04 factory date key, WRK-05 open-punch presence (G8 helper), WRK-06 `asResult`, WRK-07 transaction (no index), WRK-08/09/10/11 validation, WRK-12 date/shift staffing, WRK-13 guards, WRK-14 server soft-check + shift default, G9 release on clock-out, G11, G12, G14, G15.

Needs schema (batch into one owner-run migration per D9): partial unique index (G6/WRK-07), `releasedById` + `releaseReason` (G4), `role` (G2), optional `startedAt` (G10 accurate hours), later optional `MisProductionLog.workerAllocationId` (G7 phase 2). Keep each additive and nullable so the migration is safe on a table with 0 live rows.
