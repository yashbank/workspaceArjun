Split into four parts by screen area, each with its own build + verify pass. Legend: **Status** fixed = changed in this phase; left = logged, not fixed (reason given).

## Walk coverage (before any fix)

All 8 roles × 65 routes × 4 widths (2,112 loads): 0 crashes, 0 console exceptions, 0 page-level horizontal overflow. The only 404s were the two already-known ones (`/mis/settings/rules` for non-Owner roles per D25; `/mis/production/sign-off/none` — no phase id in the walk fixture). One non-refusal console warning (`ERR_INCOMPLETE_CHUNKED_ENCODING` on a WORKER traceability load, a role with no MIS access — not reproducible, not investigated further). Everything else logged below came from comparing screenshots and measured tap-target/font/clipping metrics against the design.
